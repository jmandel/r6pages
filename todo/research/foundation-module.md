## Change summary
- **Resource index updates — semantic guidance/navigation.** R4 listed `Topic`, `DocumentManifest`, and `MessageDefinition`. R6 ballot4 lists `SubscriptionTopic` and `SubscriptionStatus`, omits `DocumentManifest`, and omits `MessageDefinition`. These are not normative requirements on this page, but they guide readers to current Foundation resources.
- **Subscription changes — substantive in underlying model, page-level semantic guidance.** `Topic` was renamed to `SubscriptionTopic` (`7ef9e86...`), and `SubscriptionStatus` was added (`a8762c...`). Jira/Confluence/Zulip evidence shows this was part of the Argonaut/R5 subscription redesign, including a new notification Bundle type and SubscriptionStatus resource.
- **DocumentManifest removal — substantive resource lifecycle change, page-level navigation update.** `ea9417...` removes `DocumentManifest`; `FHIR-38865` and OO minutes explicitly approve removing DocumentManifest after R5 ballot notice and limited/no objection.
- **MessageDefinition removal from this module page — semantic navigation/update.** `0b361f...` removes `MessageDefinition` while adding roadmap categories. I found no page-specific Jira/Zulip/Confluence rationale for this line; it appears as part of a broader roadmap/module cleanup.
- **Developmental roadmap — semantic guidance/editorial.** The roadmap changes from “5th release” to “6th release” and adds resource maturity/use buckets. This is not REST/search/operation semantics, but it conveys implementation/maturity expectations.
- **Metadata/template/navigation — mechanical/noise.** `d7b8da...` removes the old bootstrap wrapper `<div class="col-12">`; `270e0c...` changes the owner label from “Work Group” to “Responsible Owner: Work Group”. No direct conformance semantics.
- **No examples/terminology/operation semantics changed in this page.** The changed content is module index, maturity/roadmap text, and template/metadata boilerplate.
- **Current-page cleanup noticed.** The R6 page still says “here have been significant redesigns” (`source/foundation-module.html:104`) and has empty trailing-colon items for Subscription/SubscriptionStatus/SubscriptionTopic (`:108-110`). It also still describes Subscription* as “undergoing trial use” after PR #3901 changed their StructureDefinition `structuredefinition-standards-status` from `trial-use` to `normative`; that needs WG triage rather than an assumption of error.
